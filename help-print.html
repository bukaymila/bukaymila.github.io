Cold Box Suite — User & Maintainer Guide

1. Overview

The Cold Box Suite is a set of small, self-contained web tools designed for processing cold-box recorder data — extracting temperature and humidity readings, cleaning and reshaping CSV files, visualising results, and training simple predictive models.

Each tool is a single HTML file that opens in any modern browser. No installation, no server, no internet connection is required for most tools (a small number load charting libraries from the web — see Handover Notes §5.3 for details). Everything runs entirely inside the browser on your own computer. No data leaves your machine.

1.1 What each tool does

ToolOne-line purpose
U07B ExtractorReads U07B recorder CSVs, pulls out temperature and humidity, merges multiple files into one clean table
CSV ProcessorCleans and reshapes a large CSV: find/replace, keep every Nth row, add a minutes column, split into chunks
CSV AggregatorCombines multiple CSVs by header name, producing average/minimum/maximum per row for each group
Line Chart StudioTurns a CSV into one or more line charts with full control over axes, colours, and reference lines
Shaded Chart StudioSame as Line Chart Studio but adds a shaded band between minimum and maximum values
STL 3D ViewerOpens STL files and displays them as rotatable 3D models with measurement readouts
Model BuilderTrains simple predictive models on a CSV and lets you predict new values or save/load the model

1.2 How the tools fit together

A typical cold box analysis flows like this:

Not every workflow uses every tool. The aggregator and chart studios are independently useful; the ML Model Builder stands alone.

2. Getting Started

2.1 Opening the suite

Double-click index.html. It opens in your default browser and shows a launchpad with a card for each tool. Click any card to open that tool in a new browser tab.

Each tool is also a standalone file — you can bookmark or open any individual tool directly without going through the launchpad.

2.2 Browser requirements

The suite works in any recent version of Google Chrome, Microsoft Edge, Mozilla Firefox, or Apple Safari (14 and later). For best performance with very large files, use Chrome or Edge. The STL Viewer and the chart tools use modern JavaScript features that require an up-to-date browser from the last two years.

2.3 Where downloads go

When a tool produces a file, it uses your browser's normal download mechanism. By default this is your Downloads folder. To control where files go:

  • Chrome / Edge: Settings → Downloads → "Ask where to save each file before downloading".
  • Firefox: Settings → General → Files and Applications → "Always ask you where to save files".

Alternatively, change your default Downloads folder to a project-specific one so everything lands in one place.

2.4 File format expectations

All CSV tools expect comma-separated values with a header row and UTF-8 or ASCII encoding. Blank cells are treated as missing values, not zeros.

Semicolon-separated files The tools do not currently handle semicolon-separated files. Convert to comma-separated first.

2.5 A note on privacy

Everything runs locally. Nothing is uploaded, nothing is tracked, nothing phones home. The only exception is that a few tools fetch a charting library from a public content delivery network the first time they load.

3. The Tools

Each section below explains one tool: what it's for, what it needs, what it produces, and how to use it step by step.

3.1 U07B Extractor Works offline

Purpose. Reads U07B temperature/humidity recorder CSV exports. These files contain a block of device metadata at the top, followed by the actual data table. The extractor finds that data table, pulls out the temperature and humidity columns, and merges one or more files into a single clean CSV with an "hours" column prepended.

Inputs. One or more .csv files in U07B format. All files must have the same number of data rows.

Output. A single CSV with columns:

ColumnMeaning
hoursTime in hours, 10-minute intervals (0.166667, 0.333333, 0.5, …)
<file>_temperatureTemperature in °C from each file
<file>_humidityRelative humidity in %RH from each file

Step-by-step

  1. Open the tool from the launchpad.
  2. Click Select CSV files and choose one or more U07B CSVs.
  3. Confirm the file list appears.
  4. Click Process & Merge. A progress bar shows parsing progress.
  5. Preview the first 10 rows to verify the numbers look sensible.
  6. Click Save merged CSV… and choose where to save.

Options

None — the tool detects the header row automatically by searching for a line beginning with Date,Time,Temperature.

Common errors

ErrorCauseFix
Could not find data header rowFile is not a U07B exportCheck for a line beginning with Date,Time,Temperature
Row count mismatchFiles have different row countsCrop all files to the same length
No data rows foundHeader found but rows were blankConfirm the file is not truncated

Tips

  • You can process a single file — the tool does not require two or more.
  • Column names come from the input filename, so give files meaningful names.

3.2 CSV Processor Needs internet for chunk export

Purpose. A four-step pipeline for cleaning and reshaping a large CSV. Designed for time-series data recorded at 1/10-second intervals, where you often want to reduce to one row per minute and add a readable minutes column.

Inputs. A single CSV file.

Output. Either a single CSV or a ZIP archive of several CSV chunks.

Step-by-step

Step 1 — Upload. Click Select CSV File. Progress is shown. The number of rows loaded is displayed.

Step 2 — Find & Replace. A preview of the first 10 rows appears. Type text to find and replace, optionally tick Case sensitive, Exact cell match, or leave Preview only ticked to see the effect before committing. Click Apply to All Rows. Click any row in the preview to copy a specific cell value into the Find box.

Step 3 — Keep Nth Row & Add Minutes. Default is every 600th row (one minute of data). Change as needed. Two checkboxes:

  • Add "minutes" column at the beginning — prepends elapsed minutes for each kept row
  • Round to 2 decimal places

Click Apply & Keep Selected Rows.

Step 4 — Split & Export. By default exports as one CSV. Untick Don't split to split into chunks and download as ZIP. Click Process & Export.

Worked example

A 36,000-row file at 1/10-second intervals spans exactly one hour. Keeping every 600th row gives 60 rows — one per minute, labelled 0, 1, 2, … 59.

Common errors

ErrorCauseFix
File read errorFile locked or not a text fileClose it in Excel and try again
No data rowsOnly a header, no rows beneathCheck the file content
ZIP download failedZIP library could not be fetchedSee §5.3

3.3 CSV Aggregator Works offline

Purpose. Combines multiple CSVs by matching column header names. Where two files both have a column called Temp_C, both are treated as the same measurement, and the tool produces average, minimum, and maximum across all matching columns, row by row.

Inputs. Two or more CSVs with compatible headers. Columns with names that do not match any other file are dropped. Rows beyond the shortest file's length are ignored.

Output. A table with three columns per unique header name: <header>_avg, <header>_min, <header>_max. Downloadable as CSV.

Step-by-step

  1. Drag and drop CSV files onto the upload area, or click Choose CSV files.
  2. Files appear as removable tags.
  3. Click Aggregate.
  4. A summary shows how many files, rows, and unique headers were processed.
  5. Click Download CSV to save.
Column dropping is deliberate If a column contains any non-numeric value, the entire column is dropped. This prevents meaningless averages of text with numbers.

Common errors

ErrorCauseFix
No numeric columns foundEvery column has a non-numeric cellClean data first with CSV Processor
All columns droppedHeaders differ between filesRename so headers match exactly

Tips

  • Header names must match exactly — Temp_C and temp_c are different columns.
  • The shortest file sets the row count limit.

3.4 Line Chart Studio Needs internet

Purpose. Turns a CSV into one or more line charts. Supports multiple series per chart, drag-and-drop movement of series between charts, custom axes, reference lines, and high-resolution PNG export.

Inputs. A CSV with the first column as X-values and one or more additional columns as Y-series. Numeric X produces a numeric axis; text X produces a categorical axis.

Output. On-screen charts, plus downloadable PNGs.

Step-by-step

  1. Upload a CSV, paste a URL, or click Load Sample.
  2. The first chart is created automatically with all series.
  3. Each chart has an editable title, export and delete buttons, theme picker, point size control, reference-line and decimation controls, and axis settings for both X and Y.
  4. Drag any series tag from one chart onto another to move it.
  5. Removed series appear in the Available Series Library at the top.
  6. Click Add New Chart to create an empty chart.
  7. Click Export All (Stacked PNG) for a composite image.

Options

OptionEffect
ThemeApplies a preset colour palette to all series in the chart
Point size0 hides markers (line only)
Reference line YHorizontal dashed line at the given Y value
Reference line XVertical dashed line at the given X value
DecimationShow only every Nth point
Global X/Y titleApplies to charts without their own title

Common errors

ErrorCauseFix
CSV must have header + dataFile is empty or one lineCheck the file
No valid data series foundAll data columns are non-numericConfirm your CSV contains numbers
Chart is blankAll points null in visible rangeCheck axis min/max
Export produces nothingPop-up blocker interferedAllow pop-ups for this page

3.5 Shaded Region Chart Studio Needs internet

Purpose. A specialised version of Line Chart Studio that expects aggregated data in _avg, _min, _max form (as produced by the CSV Aggregator). It draws the average as a solid line and shades the region between the minimum and maximum — ideal for tolerance envelopes, confidence bands, or spread visualisation.

Inputs. A CSV with columns named like Time, Sales_avg, Sales_min, Sales_max, Profit_avg, Profit_min, Profit_max.

Output. On-screen charts with shaded bands, plus PNG exports (white or transparent background).

Step-by-step

  1. Upload a CSV, or click Load Sample.
  2. Charts are created automatically — one per avg/min/max group.
  3. Choose View Mode: Separate Charts or Stacked Chart.
  4. Toggle Show MIN/MAX Shaded Region at the top.
  5. In Separate mode, each chart has its own title, colour, axis, and export controls.
  6. In Stacked mode, each series has a colour picker.

Common errors

ErrorCauseFix
No complete avg/min/max groups foundColumn names do not end in _avg, _min, _maxRename columns or run through CSV Aggregator first
Shaded band does not appearToggle is offTick Show MIN/MAX

Tips

  • The Aggregator produces exactly the format this tool expects. Chain them for end-to-end workflow.
  • Transparent-background exports are useful when the destination page is not white.
  • Prefer Separate mode when you have more than six series.

3.6 STL 3D Viewer Needs internet

Purpose. Loads STL (stereolithography) 3D model files and displays them as interactive, rotatable 3D objects with automatic scaling, dynamic grid, and dimension readout.

Inputs. A single .stl file (binary or ASCII).

Output. On-screen 3D model with size displayed in millimetres.

Step-by-step

  1. Click Open STL File and choose a file, or drag an STL onto the browser window.
  2. The model is centred and scaled to fit the view automatically.
  3. Mouse: left-drag to rotate, right-drag to pan, scroll to zoom.
  4. Read the model's bounding-box dimensions in the Size box.
  5. Use Center & Reset View or Toggle Grid as needed.

Common errors

ErrorCauseFix
STL parsing failedFile is corrupted or not STLOpen in a CAD tool and re-export
Nothing appearsWebGL unavailableUse Chrome or Edge; enable hardware acceleration

Tips

  • Binary STL loads faster than ASCII.
  • Very large meshes may be sluggish. Decimate in CAD first.

3.7 Model Builder Needs internet

Purpose. Trains a simple predictive model on a CSV and lets you inspect metrics, see the fitted equation, predict new values, save the trained model, and continue training on new data.

Inputs. A CSV file with a header row. The tool streams the file, so it handles large files well.

Output. A saved model file containing the type, feature and target names, scaler parameters, equation coefficients (linear/poly), the XGBoost booster, and metrics.

Step-by-step

  1. Open the Model Builder from the launchpad.
  2. Under 1. Load Data, select a CSV file.
  3. Select Feature columns (X) and Target column (y).
  4. Under 2. Train Model, choose an algorithm:
    AlgorithmBest for
    Linear RegressionStraight-line relationships
    Polynomial (deg 2)Curved relationships, mild non-linearity
    Polynomial (deg 3)Stronger curvature
    XGBoostComplex, non-linear, interaction-heavy data
  5. Click Train Model. The tool splits 70/15/15, tunes on the validation set, and scores once on the test set.
  6. Three metric boxes appear — Train, Validation, and Test — each showing RMSE, MAE, and R².
  7. A scatter plot shows predicted vs actual on the test set.
  8. For linear/poly models, the equation appears in original units.
  9. Under 4. Predict, enter feature values and click Predict.
  10. Under 3. Save / Load Model, download or upload a model file.

Common errors

ErrorCauseFix
Need at least 30 valid rowsFewer than 30 rows survivedCheck for blanks in feature or target columns
Target must not be a featureTarget also selected as featureDeselect it from the feature list
XGBoost failed to loadLibrary could not be fetchedSee §5.3
R² is negativeModel worse than predicting the meanRelationship may not exist, or wrong algorithm

Tips

  • Always check the Test R², not the Train R². A perfect train score with a poor test score means overfitting.
  • Polynomial degree 3 or higher can overfit badly on small datasets.
  • Continue Training is useful for online learning — load a saved model and feed it new data from the same setup.

4. Troubleshooting

My CSV uploads but shows no rows

  • Check the file actually has data rows below the header.
  • Confirm the file uses commas, not semicolons or tabs.
  • Confirm the file has a header row.

Numbers look wrong

  • Excel sometimes treats IDs or codes as numbers and strips leading zeros. Prefer processing the original export.
  • Scientific notation is parsed correctly but may display rounded in previews.

Download didn't start

  • Some browsers block automatic downloads. Look for a notification in the address bar and allow downloads.
  • A download manager may be intercepting the file. Disable it temporarily.
  • Chrome and Edge may show a "Keep / Discard" prompt. Choose Keep.

3D viewer is blank

  • WebGL is disabled. Enable hardware acceleration, or try a different browser.
  • The STL may have zero triangles. Verify in a CAD tool.

Chart is slow with large files

  • Use the Decimation control in Line Chart Studio.
  • Set point size to 0 for dense data.
  • Split into chunks with the CSV Processor and chart separately.

The page is blank / nothing loads

  • Check the browser console (F12 → Console) for errors.
  • If there is no internet, chart tools and the Model Builder will not load their libraries. See §5.3.

5.2 Technology stack

All tools are single-file HTML documents — no build step, no bundler, no package manager. Every file contains its own HTML, CSS, and JavaScript. Editing is done with a text editor.

Two files are shared across the whole suite:

  • theme.css — colours, typography, buttons, inputs, tables, callouts, and the prefers-color-scheme dark-mode overrides. Edit once, and every tool updates.
  • navbar.js — injects the top navigation bar into every page and highlights the current one.

5.3 External dependencies

The biggest long-term risk in this suite Every tool that uses a charting, 3D, ML, or ZIP library fetches it from a public CDN the first time it loads. If the CDN disappears, the version is yanked, or the machine has no internet, the affected tool will not work.

Tools that work fully offline: U07B Extractor, CSV Aggregator.

Tools that require internet on first load: CSV Processor (only for chunk export), Line Chart Studio, Shaded Chart Studio, STL 3D Viewer, Model Builder.

To make the suite fully offline, download each library once and store it alongside the HTML files. Then edit the HTML to point at the local copy instead of the CDN URL. This is a one-time job of about 20 minutes per tool.

The maintainer is advised to do this before the CDNs in question are retired.

5.4 Browser compatibility

Tested on Chrome, Edge, Firefox, and Safari (14+). The chart tools use Canvas rendering, the STL viewer uses WebGL, and the Model Builder uses WebAssembly (for XGBoost) and IndexedDB internally via TF.js.

Internet Explorer is not supported and will not work.

5.5 Where state is stored

Nowhere persistent. Each tool holds its working data in the browser tab only. Closing the tab, or navigating away, discards everything. There is no save/resume feature.

If a user reloads a page mid-work, they must re-upload their file. This is by design — it keeps the tools stateless and avoids privacy concerns.

5.6 Known limitations

  • No tool handles semicolon-separated or tab-separated files.
  • CSV Processor is limited by browser memory — practical ceiling around 500 MB per file.
  • Line Chart Studio slows noticeably above ~50,000 points per series without decimation.
  • The Model Builder's XGBoost component is the most fragile dependency. If it fails to load, Linear and Polynomial still work.
  • The STL Viewer shows geometry only — no colour or material properties.

5.7 Adding a new tool

  1. Create a new HTML file with the same self-contained structure.
  2. Link theme.css in the head, and navbar.js at the bottom of the body.
  3. Use CSS variables rather than hardcoded colours, so the tool automatically participates in dark mode.
  4. Add the tool to navbar.js's PAGES array.
  5. Add a card to index.html linking to it.
  6. Consider adding it to this document under §3.

5.8 Recovery if a CDN fails

  1. Open the browser console (F12) and note which URL failed.
  2. Search for that URL in the affected HTML file.
  3. Download the library from an alternative source and save it next to the HTML file.
  4. Edit the HTML to reference the local file instead of the CDN URL.
  5. Retest.

The same procedure works for offline deployments: pre-download all libraries, edit all HTML files to reference local copies, and ship the whole folder as a bundle.
